Badminton Spatio-Temporal Inference Pipeline is a computer vision system that classifies badminton stroke types directly from broadcast video footage. Using YOLO-Pose 26, the pipeline extracts player keypoints per frame and computes normalized feature vectors relative to the hip center to capture torso and limb kinematics independently of court location. A custom classification head trained on video badminton footage processes these spatial representations, leveraging heatmaps to assess model confidence and fine-tune predictions. The end-to-end script ingests raw rally footage, evaluates frame sequences, and exports a final video file complete with real-time shot type annotations.
